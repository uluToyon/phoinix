mpc-qt-bin            # video player; mpv engine in the beloved MPC-HC shape.
                      # -bin SINCE 2026-07-31 (ulu, during the first real run): the from-source
                      # build was the slow spot of the AUR phase. Repackaged upstream AppImage,
                      # same version (26.07), same binary — but it RENAMES the desktop file to
                      # mpc-qt.desktop; stage 4's KWin rule matches both wmclass spellings, so
                      # nothing else had to move. Checked before switching, see LOG.
                      # haruna EVALUATED AND REJECTED 2026-07-31 (ulu tried it, "vergiss es").
                      # KNOWN BUG in 26.07, worth remembering before blaming the config:
                      # with settings.json present but geometry_v2.json missing it segfaults
                      # in QScreen::availableGeometry() straight out of main — and the crashing
                      # run leaves exactly that state behind, so it never starts again.
                      # Cure, CORRECTED 2026-08-06 — the old one does not work on Wayland:
                      # removing settings.json is not enough, because the clean run crashes
                      # too, before it can write geometry_v2.json. It cannot bootstrap its own
                      # profile under Wayland at all. One run over XWayland can:
                      #     rm -f ~/.config/mpc-qt/settings.json ~/.config/mpc-qt/mpc-qt.lock
                      #     QT_QPA_PLATFORM=xcb mpc-qt
                      # That writes geometry_v2.json, keys_v2.json, favorites.json,
                      # playlists.json and recent.json; afterwards the normal Wayland start
                      # works again and settings.json can be put back from a copy. Verified
                      # 2026-08-06 on the live desktop, both platforms tested before and after.
                      # See docs/LOG.md 2026-07-31 and 2026-08-06.
